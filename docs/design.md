# Reference implementation

The 14-panel collage defines the student journey. A white phone-width surface uses deep navy ink, orange actions, green feedback, and violet/yellow secondary accents. Rounded surfaces have soft shadows. A compact centered wordmark is paired with back or notification controls. Home and progress destinations share the bottom tabs. The desktop shell centers the same mobile layout.

| Screen | Reference landmarks |
| --- | --- |
| Welcome | Tilted English title, orange X-Ray label, magnifier fox, green hills, bottom CTA |
| Home | Greeting, peach diagnostic card, three colored shortcuts, tab bar |
| Test choice | Heading and three selectable icon cards, orange Continue |
| Test | Progress count, skill icon, audio controls, stacked answer cards |
| Scanner | Fox inside green progress rings, skill checklist and retry |
| Result | Green level seal, skill tiles, detailed-analysis CTA |
| Skill details | Six green meters, evidence and warm focus card |
| Plan | Eight-week timeline, green completed marks, enrollment CTA |
| Materials | Category pills, filters and compact colorful file rows |
| Mentor | Violet greeting, suggestion chips and bottom composer |
| Progress | Orange plot, period filters, metric cards and fox feedback |
| Achievements | Amber badge, green progress, six achievement tiles |
| Profile | Fox/avatar, level pill, shortcut list and settings |
| Enrollment | Graduation fox and course benefits over hills, form and status |

Use Telegram's native status bar when available. Browser screenshots display the application surface. The logo is a typeset approximation from the supplied collage. The fox is original vector artwork. Real data replaces example names, levels, percentages and metrics. The public preview uses clearly labeled, isolated sample state.
